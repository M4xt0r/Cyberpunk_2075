# Cyberpunk 2075 — système Foundry VTT

Système de jeu sur mesure pour Cyberpunk 2075 (règles en d20), pour Foundry VTT v13.
Notion reste la source de vérité des règles et du contenu ; ce système en est la version jouable à distance.

## Installation

Dans Foundry : **Systèmes de jeu → Installer un système**, puis coller ce lien de manifeste en bas de la fenêtre :

```
https://github.com/M4xt0r/Cyberpunk_2075/releases/latest/download/system.json
```

Les versions suivantes s'installent avec le bouton **Mettre à jour** du système.
